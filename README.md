`libeml` — Earl Machine Learning Library
A modular machine learning library being developed from scratch in C/C++.
The goal is to provide reusable building blocks for numerical computing,
data processing, optimization, classical machine learning, and eventually
neural-network workloads.
```text
C/C++ → Linear Algebra → Preprocessing → Optimization → ML Models
```

A layered Java application built around software architecture and database
design principles.
```text
Presentation
      ↓
Business
      ↓
Data Access
      ↓
```

dsaLib

Includes implementations for data structures and algorithms with modular

STL Replica
